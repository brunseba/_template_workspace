# Evidence Files for Mermaid Tools Testing

This directory contains evidence files demonstrating the functionality of the mermaid-tools package.

## Input Files (Source Markdown)

### Markdown Files with Mermaid Diagrams
- `sample_flowchart.md` - Contains 3 flowchart diagrams of different types
- `sample_sequence.md` - Contains 3 sequence diagrams showing different scenarios
- `sample_class.md` - Contains 3 class diagrams demonstrating OOP concepts

### Direct Mermaid Files
- `sample_direct.mmd` - Direct mermaid file for testing
- `complex_sequence.mmd` - Complex sequence diagram example

## Output Files (Generated)

### Extracted Mermaid Files (.mmd)
These files were generated by running: `mermaid-tools extract tests/evidence/`

**From sample_flowchart.md:**
- `sample_flowchart_graph_TD.mmd` - Basic flowchart (Top-Down)
- `sample_flowchart_flowchart_LR.mmd` - Process flow (Left-Right)
- `sample_flowchart_graph_TB.mmd` - Subgraph example (Top-Bottom)

**From sample_sequence.md:**
- `sample_sequence_sequenceDiagram.mmd` - Basic sequence diagram
- `sample_sequence_sequenceDiagram_2.mmd` - Authentication flow
- `sample_sequence_sequenceDiagram_3.mmd` - Error handling sequence

**From sample_class.md:**
- `sample_class_classDiagram.mmd` - Basic class diagram
- `sample_class_classDiagram_2.mmd` - University system classes
- `sample_class_classDiagram_3.mmd` - Payment system interfaces

### Draw.io Files (.drawio)
These files were generated by running: `mermaid-tools to-drawio mermaid_diagrams/`

**Consolidated File:**
- `mermaid_diagrams.drawio` - All extracted diagrams in one multi-page Draw.io file

**Advanced Individual Files:**
Generated by running: `mermaid-tools extract tests/evidence/ --advanced-drawio`
- `sample_class_advanced.drawio` - Class diagrams with advanced XML structure
- `sample_flowchart_advanced.drawio` - Flowchart diagrams with advanced XML structure
- `sample_sequence_advanced.drawio` - Sequence diagrams with advanced XML structure

## How to Use These Files

### To Extract Diagrams:
```bash
# Extract all diagrams from markdown files
mermaid-tools extract tests/evidence/

# Extract with verbose output
mermaid-tools extract tests/evidence/ -v

# Extract with advanced Draw.io generation
mermaid-tools extract tests/evidence/ --advanced-drawio
```

### To Generate Draw.io Files:
```bash
# Generate consolidated Draw.io file
mermaid-tools to-drawio mermaid_diagrams/

# Generate with specific output name
mermaid-tools to-drawio mermaid_diagrams/ my_diagrams.drawio

# Generate with verbose output
mermaid-tools to-drawio mermaid_diagrams/ -v
```

### To Test Specific Files:
```bash
# Process specific mermaid files
mermaid-tools to-drawio -f sample_direct.mmd -f complex_sequence.mmd
```
